4 Mas conexiones

Actualizamos el df creando las variables con la hora redondeada y con la hora especifica del dia.

# Horas y dias 
df <- df %>%
  mutate(HoraR = floor_date(Hora, unit = 'hour'),
         HoraDia = hour(HoraR))

df %>%
  ggplot(data = ., mapping = aes(x = HoraDia)) +
  geom_bar() + 
  labs(title = 'Conexiones realizadas cada hora')

Teniendo en cuenta el apartado anterior, tomamos los registros que tengan una hora entre 2 y 4.

# Eventos entre 2 y 4
